# Awesome Digital Holographic Imaging

A bilingual, source-aware bibliography for **digital holographic imaging and measurement**. The main curated index is [README.md](README.md) (Chinese/English). Unlike broad computational imaging or holographic-display lists, this project prioritizes recorded optical holograms, numerical refocusing, particle localization, microscopy, and underwater in-line imaging.

**Browse**: [Reviews](resources/reviews.md) · [Software](resources/software.md) · [Localization](resources/localization.md) · [Hardware](resources/hardware.md) · [Datasets](resources/datasets.md) · [Learning](resources/learning.md) · [Evaluation](EVALUATION.md) · [CSV catalog](data/resources.csv).

**Caution:** open-source code ≠ complete runnable pipeline ≠ measured 3-D accuracy. Real images without per-object independently measured depth should not be marketed as a depth benchmark. Last curated: 2026-11-03.
