# Evaluation and evidence rules / 科学评价与证据规范

## Resource labels

- **Source verified:** 原作者仓库/出版社/数据存档页面存在。**不意味着**代码运行成功。
- **Code inspected:** 已核查公开代码能够计算的输出；不暗示数据完整。
- **Author demonstration:** 论文或官方演示曾运行；不暗示当前版本直接复现。
- **Independent GT:** 真正独立测量（如带刻度位移台、已知几何/可认证深度参考）的颗粒位置或尺寸。
- **Synthetic GT:** 代码生成的真值，可以测试数值链路；存在前向/逆向模型过度一致风险。
- **Unlabeled real data:** 真实采集的全息图或裁剪图；未提供z和尺寸真值，不能计算绝对精度。

## Checklist before using any repository as a research baseline

| Gate | Required questions |
|---|---|
| Geometry | 同轴/离轴/双相机？有无物镜？原始还是处理后全息图？ |
| Optical contract | 波长真空/介质换算、像元、放大率、折射率、z方向和传感器参考面是否明确？ |
| Detection | 是否整图检测多个目标？是否靠人工或GT给出ROI？ |
| Axial position | 每个颗粒独立z，还是整幅图一个z？是否能避免边界选焦？ |
| Size | 等效半径、阈值直径、物理尺寸真值各是什么？ |
| Truth | 人工视觉焦面、合成z、机械known-z是否分开？ |
| Code | 模型权重、数据、配置、依赖、许可证及输入合同是否成套？ |
| Benchmarks | 漏检、误检、MAE、最坏误差、运行时间与内存是否完整？ |
| Scope | 能否从单颗粒扩展到多颗粒、遮挡和浑浊？ |

## Common traps / 常见误判

- 仿真中的 `z_center` 需确认真实传感器参考面与历史生成版本后才可当物距真值。
- 单个拟合球的RMSE只能表示该模型与图像的残差；不能作为独立物理位置/粒径误差。
- 全息z-stack的漂亮焦面图片，不能替代逐颗粒深度误差评价。
- 背景为空白时，零延拓引入的硬边界可产生虚假梯度峰；空白传播测试是必要的数值质量检查之一。
- 用同一样本选聚焦指标再报告最终性能属于探索性评价，不能伪装盲测。
- 公共数据集站点中的水深/采样深度通常为**仪器所在海域深度**，并非每个目标相对CMOS的轴向距离。

## Resource trust policy

本资料库只记录能由论文出版页、作者仓库、研究机构、可靠数据存档直接指向的资料；引用全文或原图必须检查第三方许可。每条资源应注明核验日期、适用构型和关键限制；不对软件精度背书。
